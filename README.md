One word, and nothing else: the word a grandma would text about AI.

The word:

> Witchcraft

A grandma does not say "large language model". She watches a machine
answer questions before she finishes asking them and calls it what it
looks like to her: witchcraft. Warm, baffled, a little suspicious — and
funny in exactly one word, with no caption needed.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, stdlib only) writes the word to `entry.txt` in the
output directory, with no trailing newline so the file is exactly the
word. It validates the gate itself: 1–30 characters, exactly one word,
not only white space.
